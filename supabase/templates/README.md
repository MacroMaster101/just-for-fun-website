# Supabase Auth email templates

Generated by `node scripts/build-email-templates.mjs`. Don't edit the HTML
files by hand: change the script and re-run it.

To install one: Supabase → Authentication → Emails → Templates → pick the
template → set the **Subject**, switch the body to **Source**, paste the
file's contents, then **Save changes**.

Style A = Simple & Clear, C = Code, F = Security notice. Every email follows
the reader's light or dark mode.

| Supabase template | File | Subject | Style |
| --- | --- | --- | --- |
| Authentication → Confirm sign up | `confirm-signup.html` | `Confirm your email for Just For Fun` | A |
| Authentication → Invite user | `invite-user.html` | `You're invited to join Just For Fun` | A |
| Authentication → Magic link or OTP | `magic-link.html` | `Your Just For Fun sign-in link` | A |
| Authentication → Change email address | `change-email.html` | `Confirm your new email for Just For Fun` | A |
| Authentication → Reset password | `reset-password.html` | `Reset your Just For Fun password` | A |
| Authentication → Reauthentication | `reauthentication.html` | `Your Just For Fun verification code: {{ .Token }}` | C |
| Security → Password changed | `password-changed.html` | `Your Just For Fun password was changed` | F |
| Security → Email address changed | `email-changed.html` | `Your Just For Fun email address was changed` | F |
| Security → Sign-in method linked | `identity-linked.html` | `A new sign-in method was added to your Just For Fun account` | F |
| Security → Sign-in method removed | `identity-unlinked.html` | `A sign-in method was removed from your Just For Fun account` | F |
| Security → Phone number changed | `phone-changed.html` | `Your Just For Fun phone number was changed` | F |
| Security → MFA method added | `mfa-added.html` | `Two-factor sign-in was added to your Just For Fun account` | F |
| Security → MFA method removed | `mfa-removed.html` | `Two-factor sign-in was removed from your Just For Fun account` | F |

Security notices also need their toggle switched on in the same Emails page.
The site doesn't use phone sign-in or MFA, so Phone number changed and the two
MFA notices never trigger today; they're branded so nothing goes out unstyled
if those features are added. Check each template's variable chips in the
dashboard match the placeholders used here.

Link expiry in the copy says 1 hour, matching Supabase's default email
OTP expiry (Authentication → Sign In / Providers → Email). Update
`EXPIRY` in the script if you change that setting.
